# Security

Do not commit secrets or credentials to this repository.

Examples include:

- API keys;
- cloud credentials;
- private tokens;
- passwords;
- database connection strings containing secrets.

For a security vulnerability in the software, use a private security-reporting mechanism once one has been configured for the repository. Do not publish an exploitable security detail in a public issue before the project has had an opportunity to investigate it.

Until a dedicated security contact is configured, treat the repository maintainer as the point of contact through the repository's available private communication channels.
