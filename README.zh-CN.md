# Counterfactual Economy（反事实经济）
### 一个用于模拟不同经济历史路径的开源平台

> **探索可能的经济世界，而不是制造一个“唯一的未来预测”。**

Counterfactual Economy 是一个开放源代码项目，尝试把历史经济重新构造成透明、可扩展、可验证的计算模拟系统。

长期目标是把以下要素连接到同一个模拟框架中：

- 历史与实时经济数据；
- 多种经济理论和经济机制；
- 家庭、企业、银行、政府及其他经济主体；
- 生产网络和国际贸易网络；
- 资产负债表与金融传染；
- 政策决策；
- 不确定性、蒙特卡洛模拟与情景分析；
- 轻量级 2D 交互界面和可扩展 Mod 系统。

同一套经济模拟内核，最终可以同时服务于**历史经济模拟游戏**和**开放的经济研究 / 政策实验平台**。

---

## 为什么做这个项目？

历史只发生了一次，但任何一个历史时点上的经济系统都存在多条可能的路径。

政府可以选择不同的利率路径；监管机构可以采用不同的住房贷款标准；一个国家可以改变税制、贸易政策、产业政策或者资本管制。

本项目希望回答：

> **如果当时采取了不同的决策，之后的世界可能会怎样？**

项目并不认为模型能够告诉我们一个“正确的替代历史”。反事实结果取决于数据、模型结构、参数、预期形成机制以及其他假设。

项目的目标是把这些假设公开、明确，并让它们可以被计算和验证。

---

## 第一个核心研究问题

第一阶段拟开展 **“2000—2008 年美国金融危机挑战”**：

> 能否使用每个历史时点当时可获得的信息，识别金融系统脆弱性不断上升的过程？

项目不应该声称模型能够准确知道危机发生的具体日期，或者提前知道某一家机构一定会倒闭。更加科学、可重复的目标是检验：危机之前的经济与金融条件是否会形成可测量的风险信号，以及不同政策是否会改变危机和宏观结果的概率分布。

## 总体架构

```text
历史 / 实时数据
        │
        ▼
   数据标准化层
  数据版本 / 单位 / 修订
        │
        ▼
 ┌──────────────────────┐
 │     Economic Core    │
 │                      │
 │ SFC + ABM + IO +     │
 │ Financial Networks   │
 └───────────┬──────────┘
             │
             ▼
       理论 / 政策模块
             │
             ▼
    校准 / 验证 / 蒙特卡洛
             │
             ▼
       反事实模拟引擎
             │
        ┌────┴────┐
        ▼         ▼
      游戏UI    研究UI
```

仓库的早期版本会故意包含较多设计文档、研究问题和数据规范，而不是急于开发完整界面。第一目标是把一个可重复的研究问题定义清楚。

## 设计原则

### 1. 模型优先于画面

第一版优先计算模拟和可复现性，而不是高清画面。低分辨率 2D 界面完全可以满足需求。

### 2. 用“机制模块”表达经济理论

不同经济理论应该成为明确、可替换的机制和假设，而不是简单的“经济学派选择按钮”。

### 3. 历史信息集必须被尊重

如果实验要回答“当时的人能够知道什么”，就不能直接使用今天修订后的数据。历史数据 vintage 应该成为系统的核心概念。

### 4. 现实历史是校准锚点，而不是强制答案

真实历史应该用于校准、验证和衡量偏差，而不是因为玩家的结果不同于历史就偷偷把结果改回去。

### 5. 不确定性是功能，而不是缺陷

输出应该经常表现为概率分布、范围和情景树，而不是一个确定数字。

### 6. 可复现性是产品功能

一次严肃的实验，应当能够通过数据版本、模型版本、参数、假设和随机种子重新运行。

### 7. 允许证明“模型不行”

能够证明某种模型不能解释某段历史，同样是有价值的贡献。

## 第一阶段目标：2000—2008 年美国

### 初始经济主体

- 家庭；
- 非金融企业；
- 商业银行；
- 政府；
- 中央银行。

### 初始变量

- GDP；
- 通货膨胀；
- 失业率；
- 利率；
- 居民收入；
- 居民债务；
- 房价；
- 抵押贷款；
- 银行资本；
- 银行杠杆；
- 政府收入与支出。

### 初始政策变量

- 政策利率；
- 银行资本要求；
- 住房贷款 LTV；
- 财政支出；
- 部分税收参数。

## 当前状态

**阶段：概念 / 研究设计**

当前没有成品游戏，也没有已经验证的通用经济模拟器。

这个仓库的目的，是把一个个人提出的长期设想逐渐变成公开、可测试、可合作的研究与软件项目。
