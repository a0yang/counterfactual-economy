# Support

## Where to ask

Use GitHub Discussions for:

- questions about the project vision;
- economic modeling discussions;
- architecture questions;
- ideas that are not yet concrete tasks.

Use Issues for:

- reproducible bugs;
- concrete feature requests;
- data proposals;
- model proposals;
- research experiments.

## Before asking

Please search existing discussions and issues first.

When asking about a simulation result, include as much reproducibility information as possible:

- model version;
- scenario;
- data version;
- parameters;
- random seed;
- relevant logs or plots.
