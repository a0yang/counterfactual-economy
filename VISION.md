# Vision

## One sentence

Build an open computational laboratory in which historical economic data, economic mechanisms and government policies can be used to explore alternative economic histories and uncertain future scenarios.

## The problem

Economic history is usually studied through completed narratives. Policy debates are often expressed through static charts and model-specific forecasts. Games simplify economic systems into a small set of numerical rules.

There is room for a transparent system that connects these worlds:

**data → institutions → agents → markets → feedback → historical outcomes**

## What this project is not

- Not a machine that knows the future.
- Not a claim that one school of economics is universally correct.
- Not a black-box AI oracle.
- Not a replacement for professional central-bank, government or investment-bank models.

## What this project should become

A shared experimental environment where different models can be compared under the same historical conditions, where assumptions can be inspected, and where counterfactual policies can be explored without hiding the uncertainty involved.

## Four layers of use

### 1. Game

A player manages a country through history and experiences the consequences of policy choices.

### 2. Historical laboratory

Researchers change one or more historical decisions and compare simulated paths with the historical baseline.

### 3. Scenario laboratory

Users define future assumptions and run multiple possible trajectories.

### 4. Model-comparison platform

Different mechanisms or theoretical assumptions can be run against the same dataset and evaluation protocol.

## Guiding principle

> **Make assumptions visible. Make uncertainty visible. Make experiments reproducible.**
