# Project Banner

The repository banner is stored at:

```text
assets/banner.png
```

The current banner is intended for the README and project landing pages. It visually communicates five ideas:

1. historical economic data;
2. economic models;
3. policy simulation;
4. 2D game/research visualization;
5. open-source collaboration.

The source concept uses a historical-industrial-to-modern-city visual metaphor with financial graphs and a global network layer.

For future redesigns, keep the project identity restrained and research-oriented rather than using a conventional “finance game” aesthetic.
