# [MODEL] Add a toy household balance-sheet example

**Labels:** `good first issue`, `model`, `python`, `area:model`, `priority:starter`

## Goal

Implement one simple household sector example with income, consumption, debt, interest payments, liquid assets, and net worth.

## Scope

This is a toy mechanism for architecture testing, not an empirically calibrated household model.

## Acceptance criteria

- Clearly document equations or decision rules.
- Include a balance-sheet identity.
- Include tests for at least two scenarios.
- State which parts are deliberately simplified.
