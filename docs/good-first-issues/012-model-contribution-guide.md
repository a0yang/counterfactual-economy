# [DOCS] Add a model contribution guide

**Labels:** `good first issue`, `documentation`, `modding`, `area:modding`, `priority:starter`

## Goal

Write a short guide explaining how contributors should propose and eventually implement new economic mechanisms.

## The guide should answer

- What problem does the mechanism represent?
- Which agents or sectors does it affect?
- What variables does it read and write?
- What equations or decision rules define it?
- Which parameters are required?
- What empirical evidence supports it?
- How can it be tested or falsified?
- What happens when the mechanism is disabled?

## Acceptance criteria

- Add the guide under `docs/`.
- Include one small example mechanism.
- Emphasize that a model contribution needs a validation plan, not only code.
