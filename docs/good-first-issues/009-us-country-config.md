# [DATA] Draft a U.S. 2000–2008 country configuration

**Labels:** `good first issue`, `data`, `model`, `area:data`, `priority:starter`

## Goal

Create a human-readable configuration describing the initial U.S. prototype.

## Candidate contents

- country identifier;
- currency;
- institutional entities;
- target model frequency;
- initial sectors;
- policy institutions;
- required data series;
- historical start/end dates.

## Acceptance criteria

- No fabricated historical values.
- Use identifiers and sources rather than hard-coding data into the configuration.
- The configuration should clearly separate structural assumptions from historical observations.
