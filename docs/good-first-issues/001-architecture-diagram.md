# [DOCS] Improve the economic architecture diagram

**Labels:** `good first issue`, `documentation`, `area:docs`, `priority:starter`

## Goal

Improve `ARCHITECTURE.md` with a clear diagram showing the relationships among data ingestion, normalization, economic mechanisms, agents, policy modules, simulation, validation, and user interfaces.

## What to do

- Keep the diagram readable in plain Markdown.
- Show data flow and feedback loops.
- Distinguish the simulation kernel from the UI layer.
- Add a short explanation of each major component.

## Acceptance criteria

- The diagram renders correctly on GitHub.
- A new contributor can understand the major components without reading source code.
- No implementation choice is presented as final unless already agreed in project documentation.
