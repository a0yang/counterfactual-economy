# [RESEARCH] Document financial-crisis variables and sources

**Labels:** `good first issue`, `research`, `data`, `area:research`, `priority:starter`

## Goal

Build a documented table of candidate variables for the 2008 Challenge.

## Suggested columns

```text
variable
concept
why_it_matters
frequency
historical_coverage
possible_sources
vintage_availability
known_limitations
```

## Acceptance criteria

- Cover at least 15 candidate variables.
- Cite the original data source or a reliable database description.
- Explicitly flag variables for which true real-time/vintage history may be difficult to reconstruct.
