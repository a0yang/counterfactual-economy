# [VISUALIZATION] Create a basic GDP + inflation 2D chart

**Labels:** `good first issue`, `visualization`, `area:visualization`, `priority:starter`

## Goal

Create the first simple research-oriented 2D visualization for the project: a time-series chart showing GDP growth and inflation for sample data.

## Constraints

- Keep it lightweight.
- Do not require a game engine.
- Prefer a notebook or small Python script for the first contribution.

## Acceptance criteria

- Include a reproducible example.
- Label units and time periods clearly.
- The chart can later be fed by real data without redesigning the plotting code.
