# Good First Issues

These are intentionally small, bounded tasks for people who want to make a first contribution without designing the entire simulation engine.

Most tasks can be completed independently. Contributors should open a pull request against the current default branch and link the relevant issue.

## Recommended first batch

| ID | Task | Area | Difficulty |
|---|---|---|---|
| 001 | Improve the economic architecture diagram | Documentation | Easy |
| 002 | Define a canonical time-series metadata schema | Data | Easy |
| 003 | Add a sample FRED-style adapter interface | Data / Python | Easy–Medium |
| 004 | Add units and frequency normalization rules | Data | Easy |
| 005 | Implement basic SFC accounting identities | Model / Python | Medium |
| 006 | Create a minimal experiment configuration loader | Infrastructure / Python | Easy–Medium |
| 007 | Build a reproducibility metadata record | Research / Python | Easy |
| 008 | Create a GDP + inflation 2D chart example | Visualization | Easy |
| 009 | Draft a U.S. 2000–2008 country configuration | Data / Modeling | Easy |
| 010 | Add a simple household balance-sheet example | Model / Python | Medium |
| 011 | Document financial-crisis variables and sources | Research / Data | Easy |
| 012 | Add a sample model contribution guide | Documentation / Modding | Easy |

Detailed issue bodies are stored in this directory so they can be copied into GitHub Issues.

## Suggested labels

```text
area:docs
area:data
area:model
area:research
area:visualization
area:infra
area:modding
area:game
priority:starter
status:discussion
status:ready
```

For the first week, it is useful to mark these issues with both `good first issue` and `priority:starter`.
